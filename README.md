# 秸秆离田信息管理系统

项目围绕秸秆离田业务，实现地块管理、秸秆上报、作业预约、订单处理、收购记录和信息管理等功能，采用前后端分离结构。

> 这是历史项目的整理版本。保留原有业务代码与依赖版本，仅整理公开配置、演示数据、初始化脚本和说明文档。此次存档没有在当前电脑上重新安装环境或验证完整运行流程。

## 功能概览

| 入口 | 主要功能 |
| --- | --- |
| 用户端（农户、合作社、作业主体） | 地块管理、秸秆上报、作业预约、订单中心、个人资料、帮助中心、消息通知 |
| 政府管理员端 | 数据看板、用户管理、公告管理、FAQ 管理 |
| 企业端 | 数据看板、秸秆审核、订单管理、收购管理、作业调度 |

## 技术栈

- 前端：Vue 3、Vite、Element Plus、Pinia、Vue Router、Axios、ECharts。
- 后端：Java 17、Spring Boot 3.2.5、Spring Security、MyBatis-Plus、JWT、EasyExcel。
- 数据库：MySQL 8.0。

依赖的具体版本以 package-lock.json 和 pom.xml 为准，存档时未升级。
